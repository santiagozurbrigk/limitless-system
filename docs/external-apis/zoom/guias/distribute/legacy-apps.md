# Legacy apps

As of September 14, 2024, all Marketplace apps use the [unified build flow](/blog/new-app-build-flows-and-optional-scopes/) for configuration and setup.

Going forward there are only 3 app types:

-   General app - uses the unified build flow UI.
-   Webhook only - uses the legacy build UI.
-   Server-to-server - uses the legacy build UI.
